# PRD Writer

기능 아이디어/티켓을 `docs/prd/` 아래 PRD 문서로 만드는 스킬. 실행 모드는 **인라인** —
PRD의 핵심 입력은 대화에 흐르는 아이디어·요구·맥락이라, 그걸 못 보는 서브에이전트로
격리하면 오히려 품질이 떨어진다.

## 문서 3종의 역할 경계

| 문서 | 질문 | 담당 |
|------|------|------|
| PRD (`docs/prd/*.md`) | 무엇을, 왜 만드는가 | **prd-writer (이 스킬)** |
| 스펙 (`docs/MSG-XXX.md`) | 어떻게 구현하는가 | spec-writer |
| 코드 | 구현 | spec-driven-dev |

파이프라인: 아이디어 → **PRD** → (지라 티켓) → 스펙 → 구현.
PRD가 이미 있으면 spec-writer가 그것을 입력으로 쓴다.

## 실행 절차

### 1. 입력 확보

- 대화에 아이디어/요구가 있으면 그대로 사용.
- MSG-XX 티켓 번호가 주어졌으면 Jira MCP(`getJiraIssue`)로 조회해 보강.
- 어느 쪽도 없으면 사용자에게 되묻는다 — 추측으로 요구사항을 지어내지 않는다.

### 2. 리서치 (작성 전 필수)

PRD의 "변경 파일 목록"과 다이어그램은 추측이 아니라 실제 코드 확인으로 쓴다:

- `.claude/docs/status.md` — 관련 패키지·인터페이스·엔티티의 현재 구현 상태.
- 영향받는 패키지를 `Glob`/`Grep`으로 확인 — 존재하지 않는 클래스를 변경 대상에 적지 않는다.
- 스펙·스키마·결정 사항과 겹치면 `../LLM-WIKI`의 `03-specs`/`04-decisions`를 타겟 grep으로 대조
  (CLAUDE.md 규칙 — 전체 탐색 금지).
- 용어는 `.claude/rules/glossary.md` 기준 (점령/방문/도감 등 — UI 노출 문구엔 "점령" 금지).

### 3. 작성

`assets/prd-template.md`를 읽고 그 구조 그대로 작성한다. 파일 경로:

- 티켓 있음 → `docs/prd/MSG-{번호}-prd.md`
- 티켓 없음(아이디어 단계) → `docs/prd/{kebab-slug}.md`, 이후 티켓이 생기면 리네임

작성 원칙:

- **요구사항에는 구현 결정을 넣지 않는다.** "keyset 커서로 조회한다"(구현)가 아니라
  "목록이 수만 건이어도 첫 페이지 응답 500ms 이내"(비기능 요구). 구현 결정은 스펙 몫.
- 기능 요구사항은 검증 가능한 문장으로 — 각 항목이 나중에 테스트 시나리오 하나로 떨어질 수 있게.
- 비기능 요구사항은 성능·보안·데이터 정합·운영 중 이 기능에 실제로 해당하는 것만. 억지로 채우지 않는다.
- 다이어그램은 mermaid(`sequenceDiagram`/`classDiagram`). 필요한 만큼만 — 단순 CRUD면
  시퀀스 하나로 충분하고, 클래스 다이어그램은 신규/변경 타입이 있을 때만 그린다.
- 확정 못 한 것은 지어내지 말고 "미해결 질문" 섹션에 남긴다.

### 4. 후속 처리

1. 생성한 PRD 경로 + 미해결 질문을 사용자에게 요약 보고.
2. 티켓이 없는 PRD였다면: 지라 티켓 생성(필요 시 분해)을 제안한다 — 티켓 설명은 PRD 요약 +
   PRD 링크로, 사람용 요약 상단 + 🤖 AI 컨텍스트 하단 형식.
3. 사용자가 "스펙 만들어줘/개발 시작해줘"로 이어가면 spec-writer / spec-driven-dev로 넘긴다 —
   이 스킬이 구현 설계까지 내려가지 않는다.

## 테스트 시나리오

- **정상 흐름(아이디어)**: "격자 사진 첨부 기능 PRD 뽑아줘" + 대화에 요구 설명 →
  리서치(status.md, video 패키지) → `docs/prd/grid-photo-attach.md` 생성 → 티켓화 제안.
- **정상 흐름(티켓)**: "MSG-260 PRD 만들어줘" → Jira 조회 → `docs/prd/MSG-260-prd.md` 생성.
- **에러 흐름**: "PRD 하나 만들어줘"만 있고 대상 기능 불명 + Jira 단서 없음 →
  무엇에 대한 PRD인지 되묻고 진행하지 않음.
