# IA — 화면 구조 (Information Architecture v2) · User Journey

프론트엔드 화면/기능 구조(IA)와 사용자 여정(User Journey)을 정리한 문서. **User Journey는
아키텍처 그림이 아니라 UX 참고용 보조자료**이며, 서비스 수준의 정본은
`.claude/docs/architecture.md`(SA)다. 이 문서는 그 SA를 화면·사용자 흐름 관점에서 보완한다.

> 목적: 화면 단위 요구사항이 어떤 백엔드 도메인/서비스에 대응하는지 빠르게 파악하기 위함.
> 실제 구현 여부는 `.claude/docs/infrastructure.md` 패키지 구조가 기준.

## 화면 구조 (IA v2)

로그인 → 메인 화면 하위에 8개 카테고리.

| 카테고리 | 주요 화면/기능 | 대응 백엔드 서비스(SA) | 구현 상태 |
|---|---|---|---|
| 온보딩 (최초 1회) | 온보딩 플로우, 위치·카메라·알림 권한 안내 | Auth | — |
| 인증 (시스템) | 로그인/회원가입, 카카오 소셜 로그인★, 로그아웃/계정 삭제 | Auth | 구현됨 |
| 설정 (상시 변경, ★신규 최상위) | 프로필 편집, 공개범위 기본값, 친구 관리, 알림 설정, 언어·정책·약관 | Auth/Social/Notification | 일부 미구현 |
| 영상 기록·업로드 (자유 길이·최대 30초) | 카메라 촬영(그 격자에서만)·갤러리 선택, AI 하이라이트 추천★, 업로드 정보(미리보기·공개범위·태그), 교체·삭제 정책 | Video, AI Highlight-Blur | 구현됨(Video) |
| 지도 기반 격자 탐색·핫구역 | 뷰포트 격자 렌더링, 탐색 모드 토글(나·친구·전체·핫), 태그·분위기 필터, 핫구역 배지★, 격자 상세(대표 영상 재생·좋아요·신고 진입) | Grid | 구현됨 |
| 개인 지도 도감·게임화 | 개인 도감 3뷰, 격자 점령/뱃지, 수집률·스트릭, 일일 도감 부스터★, 시즌 뱃지·입적, 친구 초대·친구들 격자 조회 | Collection, Social | Collection만 구현됨 |
| 안전·운영 (신고·차단·AI 프라이버시) | AI 블러 미리보기·토글★, 신고·차단 플로우, 관리자 신고 처리 화면, 정책·약관 | Moderation | **미구현** |
| 광고주·기업고객 (★신규 갈래) | 스폰서 격자 등록, 광고 성과 조회, 결제·정산 관리 | 광고(신규 도메인) | **미구현** |

★ = 필수 알림·성능 임계 기능 또는 v2에서 새로 강조된 지점.

### v2 개선점 (기획 변경 이력)

- 온보딩 / 인증 / 설정을 성격이 다른 것으로 분리 (기존엔 뭉쳐 있었음)
- 설정을 최상위로 승격 (공개범위·친구·알림 포함)
- 광고주·기업고객 진입 동선 신규 추가

## 구현 갭 (백엔드 관점)

IA·SA 다이어그램에는 있지만 `.claude/docs/infrastructure.md` 패키지 구조에는 아직 없는 도메인:

- **Social** (친구 관리) — 설정의 "친구 관리", 개인 도감의 "친구들 격자 조회"
- **Notification** (알림) — 설정의 "알림 설정", 친구 활동/뱃지/핫존 알림 Push
- **Moderation** (신고·차단·관리자 도구) — "안전·운영" 카테고리 전체
- **광고(Sponsor/Ads)** — "광고주·기업고객" 카테고리 전체, 신규 Actor(광고주·기업고객)

새 MSG-XX 티켓으로 위 도메인이 들어오면 Owner A/B 중 담당을 정하고
`infrastructure.md`의 패키지 구조·계약 인터페이스 표를 갱신할 것.

## User Journey (보조자료 · UX 참고용, 아키텍처 아님)

"외출" 여정을 Before(외출 전) / During(외출 중) / After(외출 후) 3단계로 정리. 사용자 관점의
흐름만 다루며, 서비스·데이터 계층의 정본은 SA(`architecture.md`)를 따른다.

| 단계 | 사용자 목표 | 주요 행동 | 감정·기대 | 매핑 서비스 |
|---|---|---|---|---|
| Before (외출 전) | 가고 싶은 장소·분위기를 찾는다 | 지도 격자 탐색, 핫구역·태그 필터, 대표 영상 미리보기 | "어디가 요즘 예쁠까?" 기대감 | Grid |
| During (외출 중) | 그 순간을 짧게 남긴다 | 촬영(자유 길이·최대 30초, 타이머·재촬영), AI 하이라이트 추천, AI 블러 확인, 공개범위 선택 | "빠르고 부담없이 남기고 싶다" | Video, AI Highlight-Blur |
| After (외출 후) | 다녀온 곳을 모으고 공유한다 | 개인 도감 확인, 수집률·스트릭 확인, 친구와 공유 | "내 지도가 채워지는 재미" 성취감 | Collection, Social, Notification |

각 단계의 "기회·개선점"은 SA의 8개 서비스와 매핑됨: Grid · Video · AI Highlight-Blur ·
Collection · Social · Notification.
