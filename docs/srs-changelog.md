# SRS 변경 이력

`docs/srs.md`의 요구사항이 언제 왜 바뀌었는지를 시간순으로 남긴다. 본문에서 떼어낸 이유는
병합 충돌 때문이다. 모든 SRS 작업이 이 표 끝에 행을 하나씩 붙이는데, 브랜치 둘이 같은 자리에
쓰면 매번 충돌한다. 이 파일은 `.gitattributes`에서 union 병합으로 두어 양쪽 행이 모두 남는다.

**추가만 한다.** 기존 행을 고치거나 지우지 않는다. union 병합은 수정을 중복 행으로 남기므로,
이미 적은 이력이 틀렸으면 지우지 말고 정정하는 행을 새로 붙인다.

**GitHub에서 충돌로 뜨면 로컬에서 푼다.** union 병합은 로컬 git만 적용한다. GitHub의 서버 머지는
`.gitattributes`의 merge driver를 읽지 않아서, 브랜치 둘이 이 표에 행을 붙이면 PR 화면에는 매번
충돌로 나온다. 그때는 웹에서 손으로 합치지 말고 **로컬에서 `git merge origin/develop` 후 푸시**한다.
union이 붙어 양쪽 행이 그대로 남는다. 2026-08-14에 같은 자리에서 두 번 걸렸다.
