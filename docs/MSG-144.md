| 대상 | 모델 | 베이스 | 학습 데이터 |

| 하이라이트 | PySceneDetect + 프레임 차분 (룰 기반) | — | — |

**둘 다 YOLOv11n이라 `ultralytics` 런타임 하나를 공유한다.** 모델 2개를 순차 추론해도
프로세스·의존성은 1벌이면 된다.

하이라이트에 CLIP을 붙이지 않은 이유: MSG-141이 "MVP는 룰 기반"으로 이미 확정했고,
30초 영상에 CLIP 프레임 스코어링은 과하다. `architecture.md:143`의 CLIP·pHash 표기는
Phase 2 항목으로 미룬다.

**CPU 추론 가능** — YOLOv11n은 nano급(~2.6M 파라미터)이라 GPU 없이 돈다.
MSG-143 인프라 결정에서 "GPU 필수" 제약은 걸리지 않는다. 실제 속도는 MSG-142에서 측정.

## 라이선스 — AI 레포만 AGPL-3.0

Ultralytics YOLOv11은 **AGPL-3.0**이다. 조건은 "소스 공개"이고, AGPL 13조에 따라
배포하지 않고 **네트워크 서비스로만 제공해도** 의무가 발동한다(상업 여부 무관).

FillMap에는 실질 비용이 거의 없다:

- `ASM-MSG/BE`는 이미 **PUBLIC + MIT** — 소스를 이미 공개 중이다
- AI Highlight-Blur는 `architecture.md:112` 기준 **별도 리포지토리 · 별도 프로세스 · HTTP 통신**
  → AGPL 전염 경계가 거기서 끊긴다

**결정: 새 AI 서버 레포만 AGPL-3.0으로 만든다. `ASM-MSG/BE`는 MIT 유지.**

> 전제: 상업화·창업 연계 계획 없음 (2026-07-20 성민 확인).
> 이 전제가 바뀌면 AI 레포를 permissive 스택(YuNet MIT + OpenVINO OMZ Apache-2.0)으로
> 갈아엎어야 한다. 그때 다시 열 결정이다.

### 검토했으나 채택하지 않은 대안

| 스택 | 라이선스 | 미채택 사유 |
|---|---|---|
| YuNet + OpenVINO OMZ barrier-0123 | MIT / Apache-2.0 | 라이선스는 자유롭지만 정확도 열세. YuNet은 작은·측면 얼굴에 약하고, barrier-0123은 중국 BIT-Vehicle 학습 |
| Ultralytics Enterprise License | 상용 | 유료. AGPL 조건을 지킬 수 있는 상황이라 살 이유가 없다 |

## 알려진 리스크

1. **한국 번호판 — 리스크 낮음.** 번호판 전용 한국 데이터셋은 Roboflow "Korea Car License
   Plate"(207장)뿐이라 쓸 수 없다. 다만 **우리는 블러만 하고 OCR을 하지 않는다.** 국가별
   차이는 번호판 위 문자에 있지 사각형 검출에 있지 않으므로 범용 모델로 충분하다.
   종횡비 차이(한국 구형 번호판)만 MSG-142에서 실측 확인한다.

2. **작은 얼굴·측면 얼굴 미탐지.** "사람 많은 30초" 입력이 이걸 검증하는 케이스다.
   MSG-140이 "감지 0건이어도 정상 완료"라 장애는 아니지만, 프라이버시 기능이므로
   미탐지율을 MSG-142에서 함께 기록한다. 미달 시 confidence threshold를 낮춰
   과검출 쪽으로 튜닝한다(블러는 과하게 걸려도 손해가 작다).

3. **문서 갱신 필요** — MSG-143의 "표기 불일치 정리" 완료 조건에 포함:
   - `architecture.md:142` "YOLO 얼굴 검출 → 차량번호 검출" → 구체 모델명으로 확정 표기
   - `architecture.md:143` CLIP·pHash → Phase 2로 이동, MVP는 룰 기반 명시

## MSG-142로 넘기는 입력

```
ffmpeg 디코딩 → YOLOv11n-face + YOLOv11n-plate (순차 추론) → 마스킹 → ffmpeg 재인코딩
                 └ PySceneDetect 하이라이트 구간 3개
```

측정 항목: 1건 처리 시간 / 프레임당 추론 시간 / 메모리 피크 /
ffmpeg 디코딩·재인코딩 비중(병목이 AI인지 인코딩인지 분리) / 얼굴·번호판 미탐지율.

측정 환경: 로컬 CPU + AWS GPU 인스턴스(g4dn 등).
